# CountyBuys Printful Documentation

## Authoritative architecture

`CURRENT-ARCHITECTURE-CONTRACT.md` defines the current Printful architecture and invariants.

Future implementation work must read that document first.

## Historical documentation

Files under `archive/` are historical records of prior phases, audits, implementation reports, prompts, and superseded architecture.

Historical documents may explain why code exists, but they must not override:

1. `CURRENT-ARCHITECTURE-CONTRACT.md`
2. current source code
3. current passing tests
4. live-verified provider behavior

## Archive

- `archive/phases/` — historical development phases
- `archive/audits/` — audits and investigations
- `archive/reports/` — implementation and completion reports
- `archive/legacy-architecture/` — superseded architectural documentation
